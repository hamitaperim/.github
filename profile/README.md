קהילה של אנשי טק שמגיעים למיטאפים ביחד בישראל. מוצאים מפגשים, מכירים אנשים ומשתפים ידע.

## In English

Hamitaperim is a community for tech meetups in Israel. The [meetup board](https://hamitaperim.com) brings events together, and the [public MCP server](https://hamitaperim.com/agents) lets assistants search meetups and sources.

מקימי הקהילה · [Yoan Wainmann](https://www.linkedin.com/in/yoan-wai/) · [Or Assayag](https://www.linkedin.com/in/orassayag)

Share meetup suggestions through the [site](https://hamitaperim.com/#new-source). Repository collaborators can also use GitHub Issues. For security issues, see the [security policy](https://github.com/hamitaperim/.github/blob/main/SECURITY.md).
