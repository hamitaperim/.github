# המיטאפרים · hamitaperim

Every in-person tech meetup in Israel, on one board that refreshes daily.

- **Site:** [hamitaperim.com](https://hamitaperim.com)
- **For agents:** a free public MCP server with search over meetups and sources. See [hamitaperim.com/agents](https://hamitaperim.com/agents).
- **Roadmap:** [hamitaperim roadmap](https://github.com/orgs/hamitaperim/projects/1)

## Teams

| Team | Does |
|---|---|
| maintainers | Review and merge, own the roadmap, releases and infra |
| developers | Build features and fixes through pull requests |
| designers | Design, UX copy and accessibility, review UI changes |
