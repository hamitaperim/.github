# Support

- **A meetup is missing or wrong:** use the suggestion form on [hamitaperim.com](https://hamitaperim.com).
- **A bug on the site or the MCP server:** open a bug report in the repository's issues.
- **An idea:** open a feature request.
- **A security problem:** report it privately. See [SECURITY.md](SECURITY.md).
- **Anything else:** [yoan@hamitaperim.com](mailto:yoan@hamitaperim.com).
