# Security policy

This policy covers every repository in the hamitaperim organization.

## Reporting a vulnerability

Please report it privately. Do not open a public issue or pull request until a fix is live.

Private repositories (including [hamitaperim.com](https://github.com/hamitaperim/hamitaperim.com) and [hq](https://github.com/hamitaperim/hq)) do not have GitHub's Security Advisories tab. Email [yoan@hamitaperim.com](mailto:yoan@hamitaperim.com) with "Security" in the subject line.

For a public repository that shows **Report a vulnerability** on its Security tab, you can use that form instead.

A good report says what an attacker can do, what access they need first, and the steps to reproduce. Include the affected URL or component, and leave secrets and personal information out of the report.
