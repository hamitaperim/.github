# Security policy

This policy covers every repository in the [hamitaperim organization](https://github.com/hamitaperim).

## Reporting a vulnerability

Please report it privately. Open the repository, go to the **Security** tab and choose **Report a vulnerability**. If that option is missing, email [yoan@hamitaperim.com](mailto:yoan@hamitaperim.com) with "Security" in the subject line.

Please keep the details out of public issues and pull requests until a fix is live.

A good report says what an attacker can do, what access they need first, and the steps to reproduce.
